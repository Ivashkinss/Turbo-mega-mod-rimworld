# Root review: StrategicOutpostsFoundation, 17.11

Кандидат НЕ принят и НЕ установлен. Компиляция не доказывает игровые пути. Ниже конкретные дефекты по чтению Candidate/Source, не утверждения о выполненных игровых тестах.

1. GetCaravanCommands нигде не вызывается/не патчится: игрок не получает основания/взаимодействия. CanCreateOutpostAt отвергает AnyWorldObjectAt, включая собственный караван. Основной путь неработоспособен.
2. AddPawnFromCaravan не проверяет присутствие пешки в караване, tile/faction/status; игнорирует TryAdd и не возвращает владение при отказе. Аналогичные guards нужны для выдачи/ликвидации и апгрейда удалённым/чужим караваном. Не считать комментарий atomic реализацией атомарности.
3. UI не позволяет ввести/вывести сотрудников и сырьё, забрать груз или свернуть форпост. Фабрика не снабжается игроком, только прямым вызовом из теста. При последнем работнике без допустимого каравана нельзя удалить груз/пешек.
4. Все три ThingOwner имеют один holder, но GetDirectlyHeldThings возвращает только сырьё, а GetChildHolders перечисляет дочерние holder самих предметов (например Pawn), не контейнер с произведёнными вещами. Recursive ThingOwnerUtility не видит содержимое producedGoods и сами pawn как непосредственные вещи. Нужен реальный дерево-владения (отдельные IThingHolder обёртки либо единый контейнер) плюс PostLoad cleanup/guards. Native IL в Tools/Build/StrategicRootReview/NativeApi.txt.
5. Труд вычисляется по skill ПЕРВОГО продукта и используется для всех: дерево считает Mining, смешанные направления ошибочны. Учитывать соответствующий навык каждого работника с одной долей времени на направление; dead/downed/неспособные/запрещённые работы не трудятся. Данные продуктов сейчас C# hardcode вместо запрошенных настраиваемых Def.
6. disabledByDefault лишь серый цвет. Гиперткань можно выбрать и производить бесплатно: нет фильтра ни UI, ни production. Watchtower создаёт серебро и медикаменты из ничего — пользователь этого не просил. Нужна действительная разведывательная функция либо честный ограниченный статус, без бесплатной валюты/лекарств.
7. Factory не опирается на RecipeDef и реальные требования: компоненты привязаны к Electricity вместо Fabrication; продвинутых компонентов/синткани нет; отсутствующий ResearchProjectDef пропускает проверку. При null ингредиентах можно получить бесплатные лекарства. Фракционный контент не требуется, но эти ошибки базового производства исправить.
8. При ограничении ингредиентами theoreticalOutput-unitsToProduce сохраняет целую задолженность, затем после пополнения можно выпустить старый простой сверх текущего дневного труда. Нужен только дробный остаток (<1), явная политика простоя. Нельзя сбрасывать остаток и чеканить повторно при смене продукта/специализации.
9. Суточный цикл публичен без защиты и не проверяет HasMap; Tick лишь возвращается при HasMap и после закрытия начисляет за время физической работы. lastProductionTick=0 теряет легитимный нулевой тик, +=срок теряется при last=current и разнородных interval. Проверить 1.7 нативное расписание Tick/TickInterval, не делать 1.6-only override и объявлять runtime verified.
10. Delivery Clear до DropThingsNear без подтверждённого безопасного владения/результата. Выбранный отсутствующий получатель молча заменяется первой домашней картой. Требуются предвалидация/явный выбор, сохранённый груз при сбое, реальное владение pod и отсутствие повторов после load. Товары/сырьё должны иметь stock/stack limits; TryAdd результат учитывается.
11. Upgrade TakeThings возвращает List снятых вещей (native IL подтверждён, это НЕ lazy enumerable), но результат бросается без корректного завершения/отката. Списание и upgrade должны завершаться одной подтверждённой операцией. Проверить смешанный запас склада+колокального каравана, достаточность и завершение удалённого каравана после последней пешки.
12. Английские enum/defName/Yield/Labor/None/No caravan и строки disabled выводятся игроку; отсутствующие Command textures из воздуха. Нужны настоящие существующие графические пути, EN baseline Def labels + RU DefInjected, полная локализация UI, сохранение GUI state и доступные размеры.
13. Проба RunAllChecks не имеет startup hook/MapComponent. Тест вручную обходит основание/guard capacity, skill50/150 за пределами обычного20, PostMake вызывается дважды, не делает save/load и Tick/delivery. Стоимость9->10 указана21475 вместо ceil(500*1.6^8)=21475 (это число само по себе верно), но такие формулы не заменяют native цикл. Использовать законных работников (например8×Mining~19) и настоящий караван, UI hook, silver/ingredients/ownership/day/save-load.
14. Документы заявляют100%runtime1.6/1.7, нулевой риск удаления и forward/backward compatibility без доказательств. SOURCES содержит неоднозначные/ошибочные утверждения (15дней=600000), решения по лицензиям не проверены root. Собранный snapshot не даёт таких гарантий. Исправить границы, не раздувать аудит.

Root параллельно делает clustering/world modules; исправлять только ядро форпостов в новом output. Региональное размещение/мировые караваны/фракционный контент не начинать внутри этой коррекции.
