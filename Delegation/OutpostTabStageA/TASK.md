   - **Стоимость.** Масса груза делится на 150 кг, это число капсул (минимум 1). Химтопливо = `ceil(клетки × 2.25) × капсул`, где клетки — расстояние `Find.WorldGrid.ApproxDistanceInTiles`. Если не хватает и серебра, кнопка недоступна с точной суммой в подсказке.
   - **Полёт.** Используй ванильный мировой объект летящих капсул из 1.7 (`TravellingTransporters`). Точное имя типа и API найди Cecil'ом в `Assembly-CSharp.dll`; код игры на хосте не запускать. По прибытии срабатывает своё действие прибытия:
     - в аванпост: пешки уходят в работники (как через `AddPawnFromCaravan`, с освобождением кровати), серебро — в `RawMaterials`;
     - домой: высадка как у ванильной капсулы у точки высадки домашней карты.
   - **Сохранение.** Если сохраниться посреди полёта и загрузиться, содержимое не теряется и не удваивается.
4. Действия по дизайну:
