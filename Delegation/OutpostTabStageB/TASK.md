# OutpostTabStageB — пеший караван из вкладки «Аванпосты»

kind: implement + run · assignee: gemini (Antigravity)

Дизайн: `Documentation/OUTPOST-MANAGEMENT-TAB.md`, раздел «Способы доставки», пеший караван. Этап A (капсулы) принят: `Source/MainTabWindow_Outposts.cs`, `Source/OutpostPodLogistics.cs`. Делай только этап B. Транспорт (этап C) остаётся недоступной кнопкой.

## Сделать
1. **Отправка.** В строке аванпоста в меню «Отправить работников» и «Отправить серебро» появляется второй способ — **«Пешим караваном»**. Окно выбора:
   - колонисты домашней карты (свободные, не призванные, дееспособные), у каждого флажок «остаться работником»;
   - сколько серебра нести (ползунок, не больше, чем есть на складах);
   - внизу «Дней пути: X, еды на дорогу туда и обратно: Y из Z дней». Если еды меньше, чем нужно на дорогу туда и обратно, кнопка «Отправить» недоступна, а причина написана в подсказке.
   Расчёт еды делай ванильными средствами (`DaysWorthOfFoodCalculator`, `CaravanArrivalTimeEstimator`), без своих формул.
2. **Сборка.** Караван собирается **сам** штатной механикой формирования каравана с выбранными пешками, серебром и нужной едой. Цель маршрута — клетка аванпоста. Найди API Cecil'ом через `Tools/cecil_methods.ps1 -Type <тип>`, только из файла скрипта, без `powershell -Command`. Не изобретай свой ИИ сборки.
3. **Прибытие на клетку аванпоста.** Без захода на карту:
   - серебро уходит в `RawMaterials` аванпоста;
   - пешки с флажком «остаться» становятся работниками через тот же путь, что `AddPawnFromCaravan`, с освобождением кровати. Если мест не хватает, лишние идут назад с сообщением;
   - остальные пешки сами разворачивают караван домой (цель — домашняя карта) и по прибытии входят в колонию.
4. **Отмена.** Пока караван в пути, у него есть кнопка «Вернуться домой».
5. **Сохранение.** Сохранение и загрузка посреди пути не теряют цель, флажки «остаться» и груз. Состояние храни в своём WorldComponent или в компоненте каравана, со Scribe.
6. Все строки — в EN и RU Keyed. Только C# 5: без `?.`, `=>`-членов, `nameof` и `is X x`.

## Проверка в игре (обязательна)
Проба `Tests/InGameOutpostCaravanProbe.cs`, компонент `OutpostCaravan`, и reload-скрипт. Проверки должны совершать реальные действия:
- основать аванпост тем же путём, что и проба `OutpostTab`;
- отправить караван из двух колонистов: один «остаться», второй несёт 200 серебра. Проверить, что караван сформировался и вышел к клетке аванпоста;
- проматывать время до прибытия:
  - на складе аванпоста +200 серебра;
  - первый колонист в работниках, его кровать свободна;
  - второй колонист в караване, который идёт домой;
- дождаться возвращения: второй снова на домашней карте и колонист игрока;
- без еды кнопка недоступна, причина в тексте;
- reload: сохраниться, пока караван идёт к аванпосту, загрузиться, дождаться прибытия. Серебро пришло ровно один раз, работник добавлен ровно один раз.
