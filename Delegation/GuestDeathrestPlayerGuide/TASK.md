# GuestDeathrestPlayerGuide
По снимку Tools/Build/GuestDeathrestSaveSnapshot/ подготовить руководство игрока на русском, до 45 строк, и ровно 10 сценариев ручной проверки. Результаты только Tools/Build/GeminiGuestDeathrestPlayerGuide/: GUIDE.md, MANUAL-CHECKS.md, REPORT.md.
Доступ к исходникам только чтение, без игры/сети/изменений вне выходной папки. Рабочие файлы и Git не менять.
Объяснить понятными словами: ресепшен → «Настройки служб комплекса» → гостиница → новая галочка; потребность только при активном гене; подходит обычная гостевая кровать или гостевой саркофаг под крышей; заранее оплаченный номер и запас денег на следующие сутки, без нового вступительного платежа; питание/лечение сначала; группа ждёт; выключение галочки не будит уже спящих; штатное пробуждение автоматически при 100%; прерывание через «Управление смертосном» с подтверждением и обычным последствием незавершённого цикла; чужие усилители не захватываются, прежние привязки не гарантируют ускорение в гостевом саркофаге; при смене тарифа и потере денег цикл может прерваться.
Не обещать специальную кнопку постройки «гостевого саркофага» без подтверждения в снимке: встроенный мод генерирует guest-варианты, обычный саркофаг в комплексе переходит в гостевой фонд по штатной автоматике. Не утверждать, что тесты уже пройдены, не выдумывать новые суммы/кнопки. Проверки должны включать save/load активного сна, повторный платёж, прерывание, отсутствие денег и служебную зону.
Отчёт до 60 строк: исходные пути, точные ключи интерфейса, вопросы вне статического снимка. Это документация, не ещё один аудит API.
