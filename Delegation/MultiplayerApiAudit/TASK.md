# Gemini: статическая проверка единого поставщика Multiplayer API

Пиши только в `Tools/Build/GeminiMultiplayerApiAudit/`. Не менять проект, DLL, Git, настройки/сохранения, прошлые отчёты. Не выполнять код исследуемых DLL. Только Mono.Cecil/безопасное чтение метаданных; можно использовать доверенный Cecil из `Components/Harmony/1.6/Assemblies/0Harmony.dll`. Без сети и установки пакетов.

Текущий поставщик: `Components/AdaptiveStorage/Assemblies/0MultiplayerAPI.dll`, версия 0.5.0.0, SHA256 `4689e799c50db79411b00ad8855d7df86721bf3cfe1e390b68038b6abcd852ec`.
Кандидат: `Tools/Build/GeminiClinicSurvey/Hospital/1.7/Assemblies/0MultiplayerAPI.dll`, версия 0.6.0.0, SHA256 `863766df5fd24a31eda1e59947f026abd5b8dc99cb0d7bca6a8a3d356b65ad8d`.

Обойти игровые DLL в `Components/` и наш `Assemblies/TurboMegaMod.dll`, плюс Hospital.dll 1.6/1.7 из закреплённого checkout `82a15e711129a32e5bfe772663160433ee566316`. Не считать Upstream, Source/bin/obj, Lunar резервные Harmony и тестовые DLL игровыми потребителями. Runtime ветки 1.6/1.7 отмечать отдельно, не объявлять одновременными.

Выход:
1. `CONSUMERS.json`: все AssemblyRef к 0MultiplayerAPI — путь, версия потребителя, версия ссылки, SHA256; TypeRef/MemberRef с полными сигнатурами/арностью generics и наличием в обоих поставщиках. Простое совпадение имени не считать проверкой сигнатуры. Неуверенные inherited/generic случаи отметить отдельно.
2. `API-DIFF.json`: публичные типы/методы/поля/свойства, добавленные/удалённые/изменённые между 0.5 и0.6. Не делать выводов о поведении методов по одной сигнатуре.
3. `REPORT.md`: сколько реальных потребителей/ссылок проверено, какие именно несовпадения мешают переходу, что остаётся непроверенным. Разницу AssemblyRef-версий указать отдельно: успешный статический поиск методов не доказывает runtime binding и работу Multiplayer. Реальный запуск и выбор единственного поставщика делает Codex.

Сохрани воспроизводимый анализатор в выходной папке, не удаляй полезные инструменты в конце. Источники результатов — точные SHA256 файлов, не предполагаемые номера версий из старых отчётов.
