При необходимости переработай собственный кандидат, но сохрани простую архитектуру.

Читать Core/включённые компоненты/родные DLL метаданными Cecil можно. Запись только Tools/Build/GeminiStrategicOutpostsCorrections/ и Tools/Build/GeminiWorkerState/StrategicOutpostsCorrections.json. ## Обязательный результат

- Подключённая команда на настоящем caravan.GetGizmos, корректная клетка (свой caravan не препятствие), выбор4типов, минимум2 подходящих колониста. Сохраняются те же Pawn/вещи. Проверяй статусы/фракцию/принадлежность/tile, откатывай неудачный TryAdd. Пустой caravan корректно удаляется только после успешной передачи; rollback не теряет животных/груз. Полный понятный UI работников (перевести туда/обратно), запасов (внести сырьё/серебро, забрать груз), апгрейда и эвакуации. Локальный доступ к caravan обязателен для передачи, а смена производства/получателя доступна удалённо.
- Десять уровней/cap L+1, геометрическая цена baseline500×1.6^(L-1) за переходL→L+1, Def-config; настоящее достаточное серебро, итог/guards. Большие суммы/стэки ограничены, нет уровня11.
- Нормы/товары data-driven Def; добычаMining, деревоPlants, плантацияPlants, фабрикаCrafting. Делится рабочее время на число выбранных направлений, каждый продукт считает свой skill; один сотрудник не даёт100% всем. Живые трудоспособные взрослые колонисты, учитываются запреты работ. Mining150->100пластстали/сутки; дробь сохраняется, не банковать целый простой без ингредиентов. Фабрика расходует реальные RecipeDef requirements/research/ingredients; можно поддержать узкий проверенный набор компонент/advancedcomponent/ткани с явно своим исследованием, но не бесплатную гиперткань/синткань через пустой рецепт. Неподдержанные позиции отключить и честно назвать. Watchtower никакого бесплатного серебра/лекарств; реальная read-only разведка ближайших поселений с уровнем/дальностью (мировые группы root подключит позже).
- Реальный native ticking1.7+compile1.6; 60000тиков,0валидныйтик, save дедлайна, без дубля/огромного catch-up. Пока HasMap pause + baseline без последующего начисления за то же время. World-only предел первой версии допустим, НО не открывать обычный Enter если он генерирует пустоту или теряет owner-работников; посещаемые развиваемые базы будут отдельным модулем.
- Полное дерево IThingHolder для всех сохранённых вещей/пешек. Допустимо объединить cargo в один owner с назначениями либо маленькие exposable holder-обёртки. Отсутствующий получатель/заблокированная доставка держит вещи, не подменяет выбранную колонию. Нативный pod допустим для суточной отправки; после фактической передачи настоящий владелец существует, подготовка/исключение не уничтожает груз. Физическая shipment не повторяется на reload.
- Полный RU/EN UI, Def labels EN/RUInjected, реальные проверенные игровые иконки; без enum/defName/английских заглушек/перекрывающихся кнопок. Инспектор: состав/cap/level/следующая цена/продукты и ожидаемо/сырьё/груз/получатель/дедлайн.
