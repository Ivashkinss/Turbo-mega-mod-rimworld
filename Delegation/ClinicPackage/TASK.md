# Gemini: изолированный комплект файлов Hospital

Записывать ТОЛЬКО в `Tools/Build/GeminiClinicPackage/`. Исходник `Tools/Build/GeminiClinicSurvey/Hospital/`, закреплённый SHA `82a15e711129a32e5bfe772663160433ee566316`. Черновик русского языка — `Tools/Build/GeminiClinicLocalization/Russian/`. Не менять ни исходник/черновик, ни рабочие Components/Source/Defs/Languages/Assemblies/LoadFolders/Git, игру, настройки/сохранения и старые отчёты. Не запускать DLL/игру, не использовать сеть, не устанавливать пакеты.

1. Подготовить `Package/` с НЕИЗМЕНЁННЫМИ файлами оригинала: общие Patches/ и Textures/, выбранные `1.6/Defs`, `1.6/Languages`, `1.6/Assemblies/Hospital.dll`, такие же ветки 1.7. Скопировать имеющиеся общие Languages/ и Sounds/, если реально существуют. Добавить LICENSE, README.md, CONTRIBUTING.md и About/Manifest.xml, если присутствуют. Не включать About/About.xml (это не отдельный установленный мод), 0MultiplayerAPI.dll (общий поставщик уже есть в проекте), старые версии игры, .git, bin/obj, IDE-файлы и кэши. Никакой правки XML/DLL/рисунков в Package.
2. `UpstreamSource/`: неизменённый Source/ кандидата (C#, csproj и реально нужные для сборки текстовые файлы), без bin/obj/.vs и IDE-кэшей. Цель — читаемые GPL-исходники для последующей публикации; ничего не компилировать.
3. `RussianDraft/`: копия русского черновика. Из Keyed убрать ТОЛЬКО BedsFilled и SilverMultiplier: эти совместимые ключи уже существуют в корневом Languages/Russian/Keyed/Hospitality.xml и второй раз их вводить нельзя. Другие записи/формулировки/Defs не менять. Это ещё не принятый перевод.
4. `FILES.json`: все скопированные файлы, категория, исходный путь, путь относительно новой выходной папки, размер и SHA256 исходника/копии. Для изменённого русского файла указать обе контрольные суммы, удалённые два ключа, что остальной состав сохранён. Не делать утверждение, что весь комплект raw-identical: RussianDraft/Keyed действительно отличается.
5. `REPORT.md`: количество/байты по категориям, точные исключения, подтверждение закреплённого коммита и неизменности исходника, результаты XML-парсинга копий и сверки raw-файлов. Не трогать Git рабочего проекта даже для коммитов. Наличие комплекта не называть выполненной интеграцией или совместимостью игры. Английские общие ключи не удалять из оригинальных копий: слияние и устранение конфликтов загрузки делает Codex при импорте.

Можно создать воспроизводимый `prepare_package.py` в выходной папке, записывающий только через Path(__file__).resolve().parent. Проверить, что каждый путь назначения остаётся внутри этой папки, без рекурсивного удаления каких-либо директорий.
