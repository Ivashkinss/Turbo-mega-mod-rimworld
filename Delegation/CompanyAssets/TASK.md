# Gemini: иконка обычной услуги «Составить компанию»

Выполнять после текущих ClinicLanguageMerge и ComplexGuestServicesInventory. Запись только в `Tools/Build/GeminiCompanyAssets/`. Не менять рабочие Textures/Source/Defs/Languages/Assemblies/Components/Git, игру, настройки/сохранения и прежние отчёты. Без сети, чужих изображений/шрифтов и новых пакетов. Можно читать собственные PNG из Tools/Build/GeminiComplexAssets/ для понимания визуального масштаба.

Создать оригинальную иконку `Company.png`128×128RGBA: два условных человеческих силуэта за маленьким столиком, между ними простой значок разговора и кружка. Тёплая спокойная палитра, видимость32×32/64×64, прозрачный фон, отступ непрозрачных пикселей>=8px, без текста/букв/брендов. Это обычное общение и досуг. Никаких интимных/эротических образов, обнажения, общей кровати или сексуальных действий.

`make_assets.py`: воспроизводимый генератор на уже установленном Python/Pillow,4×supersampling+LANCZOS, все назначения только через Path(__file__).resolve().parent. Ничего не устанавливать. Не искать python рекурсивно по всему диску: известный интерпретатор `C:/Users/vanya/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe`; если он недоступен — сообщить, не трогать окружение.

`preview.png`: иконка128/64/32на светлом/тёмном фоне. `manifest.json`: размер, режим, SHA256, отступы, наличие полностью прозрачных и непрозрачных пикселей. Два запуска должны давать одинаковые хеши. `REPORT.md`: файлы/проверки и отсутствие изменений вне выходной папки. Не выдавать графику за готовую игровую механику.
