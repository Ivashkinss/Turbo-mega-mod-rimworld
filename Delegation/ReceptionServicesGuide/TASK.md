# Gemini: инструкция для единого меню служб

Пользователь не нашёл расписание клиники и потребовал перенести гостиничные настройки из нижнего меню в «Настройки служб комплекса» ресепшена. Новый черновик имеет5 вкладок: Общее / Гостиница / Клиника / Ресторан / Персонал. Списки постояльцев/пациентов открываются здесь; прежние нижние кнопки Guests/Patients скрыты. В автоматическом режиме кнопки областей, персонала и госпитализации перенесены внутрь окна служб. Работающие назначения и часы не сбрасываются. Источник истины — только Tools/Build/ReceptionServicesGuideSnapshot/, хэши в SNAPSHOT.json. Codex параллельно запускает игровые проверки; их результатов ещё нет.

Писать исключительно Tools/Build/GeminiReceptionServicesGuide/ и свой статус Tools/Build/GeminiWorkerState/ReceptionServicesGuide.json по GEMINI-WORKER.md. Source/XML/DLL/Git/игру/сохранения/пользовательские настройки и предыдущие отчёты не менять, сеть/игру не запускать.

Создать GUIDE.md (русский, до70строк), MANUAL-CHECKS.md (ровно12 сценариев), REPORT.md. Объяснить доступ через ресепшен → «Настройки служб комплекса», содержимое каждой из5 вкладок и место списков. Понятно объяснить разметку: обычную разрешённую область надо создать заранее и затем выбрать в «Общее»; общая территория охватывает весь комплекс, служебная только закрытые для гостей комнаты, не запирает работников. Не предлагать отдельную гостевую область/область продуктов при автоматическом управлении. Различать врачебную палату/колониальный лазарет.

Клиника: мастер-переключатель приёма, отдельное разрешение операций, 24 местных часовых интервала, зелёный открыт/серый закрыт, кнопка «Открыть приём круглосуточно», число свободных коек/статус сейчас; приём операций не вызывает пациента немедленно, приход случаен и только в открытые часы; закрытие приёма не выписывает существующих пациентов. Гостиница: разрешение гостей не вызывает группу немедленно; показать где очередь следующего визита, что её время — план, не гарантия. Суточная цена/бесплатное питание/проверка безопасности и работа с гостями. Ресторан: нужен прилавок/официант/готовая еда, при пустом холодильнике берут из колонии. Персонал: проживание независимо от режима работы, сеансы общения и обычный учёт труда без новых придуманных механик.

Один небольшой раздел GUIDE описывает ручную теплицу: полный план на улице сохранён; можно отдельно построить стены/дверь/панель, затем выбрать стеклянную крышу на свободном полу замкнутой комнаты; крыша строится штатной работой, опоры нужны, непрозрачная кровля снимается вручную, автоматического расширения нет. Не обещать произвольный навес вне стен, бесплатную стройку или восстановление уже разобранных стен.

Ручные сценарии — планы, не отчёт о фактическом прохождении игры.
