Следующий блок для мода RimWorld 1.7 — **именное снаряжение героев**. Это ты придумывал 80 именных героев 15 фракций в этом чате. Узнаваемые вещи героев: куртка Дина, плащ и клинок Кастиэля, шляпа Престона Гарви, костюм Кроули, монокль доктора Хесс и подобное. Предмет называется по герою, его можно скрафтить, а чертёж открывается через самого героя. Код не нужен. Ответ — один блок JSON без пояснений.

## Кому
- Всем лидерам фракций и героям ранга 4.
- Самым известным героям ранга 3: тем, кого игрок узнает по сериалу или играм.
- Всего 25–35 предметов. По одному предмету на героя, иконическим героям можно два, например одежду и оружие.
- Легендарки из блока 14 (Первый Клинок, Кольт, Клинок Архангела и т.д.) не повторяй. Именные вещи слабее легендарок, это «фирменный стиль», а не абсолютное оружие.

## Формат
```json
{
  "items": [
    {
      "id": "dean_leather_jacket",
      "hero": "Дин Винчестер",
      "faction": "minutemen_hunters",
      "type": "apparel | melee | ranged | utility",
      "label_en": "Dean's leather jacket", "label_ru": "кожаная куртка Дина",
      "desc_en": "1-2 предложения, атмосферно, с внешним видом для художника", "desc_ru": "",
      "baseOn": "ванильный ThingDef для наследования",
      "layers": ["для одежды: OnSkin | Middle | Shell | Overhead"],
      "stats": { "MarketValue": 0, "Mass": 0, "ArmorRating_Sharp": 0, "ArmorRating_Blunt": 0, "ArmorRating_Heat": 0 },
      "combat": { "damage": 0, "armorPenetration": 0, "cooldown": 0, "range": 0 },
      "equippedStatOffsets": { },
      "setBonus_ru": "если у героя два предмета — бонус за полный комплект, иначе пусто",
      "cost": { "Leather_Plain": 0 },
      "workbench": "ElectricTailoringBench | FabricationBench | TableMachining | FueledSmithy",
      "unlock_ru": "как открыть чертёж: союз или квест героя, завербовать героя, снять трофей с героя",
      "special_ru": "особый эффект, если есть, и честно: ванильный XML или свой код"
    }
  ]
}
```
- Используй только существующие ванильные defName материалов. Кожа — `Leather_Plain`, а лучше укажи `"stuff": "Leathery"` вместо конкретной кожи. `Leather_Heavy` в игре нет.
- Характеристики делай на уровне фракционной одежды из блока 16 или чуть выше.
- Пиши, кто именно из героев это носит. Если герой завербован, он появляется в своей вещи.
