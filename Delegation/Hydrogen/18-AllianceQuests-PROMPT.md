Следующий блок для мода RimWorld 1.7 — **цепочки квестов союза** с каждой из 15 фракций. В блоках 14, 16 и 17 почти всё лучшее открывается «союзом с фракцией» или «квестом героя». Теперь нужно описать, как этот союз заключается. Код не нужен. Ответ — один блок JSON без пояснений.

## Правила
- **Цепочка.** У каждой фракции 3 шага: знакомство, доверие, союз. После третьего шага фракция становится союзником. Открываются её квестовые чертежи (блоки 16 и 17), а у лидера можно получить легендарку (блок 14).
- **Механика шагов.** Каждый шаг — это обычный для RimWorld квест:
  - доставить вещи;
  - защитить поселение фракции;
  - уничтожить лагерь врагов;
  - спасти или приютить героя;
  - пустить гостей в нашу гостиницу;
  - выдать пленника;
  - сопроводить караван;
  - исследовать что-то.
  Используй героев этой фракции по именам: кто выдаёт квест, кого спасаем.
- **Враги фракций.** Союз с одной фракцией злит её врагов. Укажи, кто обидится и на сколько упадут отношения. Например, Братство против Института, Небеса против Ада, Подземка против Института.
- **Пути к легендарке.** Для фракций с легендарным оружием, где награда «убивает с одного удара» (Ад, Небеса), шаг 3 должен быть заметно сложнее. Альтернативный путь — штурм главной базы — тоже опиши.
- **Где герои.** Квесты могут проходить в наших аванпостах или городах фракций (есть региональные города разных уровней), а также в гостинице колонии.

## Формат
```json
{
  "chains": [
    {
      "faction": "brotherhood",
      "enemies": [ { "faction": "institute", "goodwillChange": -40 } ],
      "steps": [
        {
          "step": 1,
          "giver": "имя героя",
          "label_en": "", "label_ru": "",
          "desc_en": "2-3 предложения письма-предложения", "desc_ru": "",
          "type": "delivery | defend | destroy_camp | rescue | host_guests | hand_over_prisoner | escort | research",
          "requirements_ru": "что именно нужно и сколько, с цифрами",
          "timeLimitDays": 0,
          "reward_ru": "награда за шаг: серебро, предметы, отношения, чертёж",
          "failure_ru": "что будет при провале или отказе",
          "implementation_ru": "честно: какие ванильные QuestScriptDef или QuestNode подойдут, где нужен свой код"
        }
      ],
      "alternative_ru": "как получить то же силой: штурм, трофей, и чем это грозит"
    }
  ]
}
```
- Требования и сроки должны быть посильными для колонии среднего уровня. Шаг 3 занимает несколько игровых дней.
- Тексты писем пиши живым русским языком, от лица героя.
