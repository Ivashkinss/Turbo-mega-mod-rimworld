## Формат
```json
{
  "rewards": [
    {
      "id": "first_blade",
      "faction": "hell_demons",
      "type": "melee | ranged | apparel | utility",
      "label_en": "", "label_ru": "",
      "desc_en": "2-3 предложения, атмосферно", "desc_ru": "",
      "baseOn": "ванильный ThingDef, от которого удобно наследовать (например MeleeWeapon_Knife, Gun_ChargeRifle, Apparel_PowerArmor)",
      "stats": { "MarketValue": 0, "Mass": 0 },
      "combat": { "damage": 0, "armorPenetration": 0, "cooldown": 0, "range": 0, "burst": 0 },
      "mechanics": [ "коротко, как реализовать эффект в RimWorld: hediff, DamageDef, comp — по-русски" ],
      "acquisition_ru": "как получить: финальный квест союза или штурм главной базы"
    }
  ],
  "borax": {
    "label_en": "", "label_ru": "", "desc_en": "", "desc_ru": "",
    "variants": [ "распылитель (оружие)", "турель с распылителем" ],
    "mechanics": [ "как бура снимает неуязвимость Дика Романа и ранит левиафанов" ]
  }
}
```
- Значения характеристик сравнивай с ванильным оружием эндгейма: легендарки сильнее, но не ломают баланс, кроме оговорённых убийств с одного удара.
- `mechanics` — честно: что делается ванильными средствами, а где нужен свой код.
