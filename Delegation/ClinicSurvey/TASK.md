# Gemini: предварительная инвентаризация платной клиники

Ресторан остаётся текущим этапом Codex. Это только подготовка исходных данных для возможного следующего этапа, без интеграции и без запуска модов.

Пиши только в `Tools/Build/GeminiClinicSurvey/`. Допустим публичный `git clone` внутрь этой папки. Не менять основной Git, Source, Components, Defs, Languages, Assemblies, настройки/сохранения игры и прошлые отчёты. Не устанавливать пакеты, не входить в аккаунты, не связываться с авторами, не выполнять загруженные DLL/скрипты.

Исходник-кандидат: `https://github.com/tomvd/Hospital` (страница автора: `https://steamcommunity.com/sharedfiles/filedetails/?id=2992224079`). Если ссылка не работает или репозиторий архивный, зафиксировать это и читать только реально указанные автором ссылки. Не подбирать похожий мод по одному названию.

Выход:
1. `PINS.json`: URL, точный SHA, ветка, дата последнего коммита, packageId, заявленные версии и реальные папки загрузки, обязательные зависимости, TargetFramework. Безопасно прочитанные AssemblyRef DLL отделить от csproj. Прямо указать, найдена ли реальная сборка для 1.7.
2. `LICENSE-EVIDENCE.md`: полные лицензионные абзацы README/About и заголовки LICENSE на точном SHA; проверить противоречия между кодом/графикой/форком. Если правила менялись, дать ключевые коммиты `git log --follow`. Не выводить разрешение на перенос только из наличия LICENSE.
3. `FILES.json`: ресурсы выбранных папок, пути/размеры/SHA256; необязательные DLC-ветки отдельно. Не включать папку .git и сборочные bin/obj как игровые ресурсы.
4. `FLOW.md`: по коду — кто считается пациентом, как прибывает/уходит, какие кровати/зоны и персонал нужны, как вычисляется счёт, когда физически передаются деньги/лекарства, какие данные сохраняются, что происходит при нехватке денег/смерти/вербовке/разрушении кровати. Каждый вывод — путь/строки. Предполагаемые баги пометить гипотезами с условиями воспроизведения.
5. `LOCALIZATION.json`: реальные EN/RU Keyed/DefInjected, пропущенные/устаревшие ключи и числовые параметры. Числовой индекс `.stages.0.` сам по себе не дефект. Старый `<rep><path>` формат учитывать отдельно.
6. `REPORT.md`: краткие факты, точные проверки packageId Hospitality/HugsLib/VEF, ограничения источников, авторские замечания о совместимости с DLC/Androids/Combat Extended. Никаких утверждений о фактически пройденных игровых тестах.

В нашем проекте Hospitality уже встроена, общий packageId `colonyproject.integrated`, Harmony/VEF/HugsLib тоже встроены. Не создавай глобальные алиасы и не исправляй проверки самостоятельно. Все выводы Codex проверит до решения об интеграции.
