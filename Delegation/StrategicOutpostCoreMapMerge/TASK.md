# StrategicOutpostCoreMapMerge — объединить исправленное ядро и посещаемые карты

Пользователь нашёл отдельные проблемы тесного расселения и стартового UI; root сейчас чинит их. Продолжай аванпосты изолированно. Твои StrategicOutpostsCorrections/StrategicOutpostMaps и частично законченная курация CodexOutpostCore сохранены. Нужно собрать один законченный игровой кандидат, а не три расходящихся версии. Не начинать фракции/сюжет/ещё один аудит мира.

## Вход и границы

Immutable Tools/Build/OutpostMergeSnapshot/SNAPSHOT.json: RootSource (актуальная общая основа), Base/Candidate (твоя коррекция), Core/Candidate (правки Codex, остановлен лимитом до законченного отчёта), Maps/Candidate (твои карты), RootReview (прежние TASK/REVIEW). Сравнивать Base→Core и Base→Maps; включить обе ветки. Частичный Core не считать полностью проверенным. Запись только Tools/Build/GeminiStrategicOutpostCoreMapMerge/ и Tools/Build/GeminiWorkerState/StrategicOutpostCoreMapMerge.json; корневые Source/Defs/Languages/Assemblies/Tools/Tests/QUEUE/Git/настройки/сейвы не менять. Не запускать игру или загружать Assembly-CSharp для исполнения; Cecil/компилятор разрешены. В конце running→done с настоящим report.

## Важные исправления, которые нельзя потерять при слиянии

1. Native WorldObject.DoTick1.7 вызывает и старый Tick(), и TickInterval(). Поэтому отсутствие overrideInterval само по себе НЕ ошибка. Если оба вызывают production — один сохраняемый дедлайн, без двойного суточного начисления. Тик0 легитимен, физическое время не начисляется снова при автономности. Public production entry не даёт многократно собирать день.
2. Суммарный Mining150→100пластстали/день при одном продукте, легальные навыки<=20. Нулевой/отсутствующий навык даёт0 (в твоей коррекции minskill0.2 ошибочно создаёт выпуск), отключённая работа/недееспособность исключает труд. Дерево=Plants. Время делится между выбранными направлениями, дробь сохраняется, целый простой без ингредиентов не банкируется. Только4варианта UI: добыча/дерево вместе; плантация; дозор; фабрика. Legacy Logging enum допустим как скрытый alias, но не пятый тип в меню.
3. Передача уже heldPawn в другой owner: нельзя TryAdd до изъятия из прежнего holder. Native transfer либо remove→TryAdd с подтверждённым rollback. Tile/Faction/Spawned/status/принадлежность — guards в actual methods, а не только UI. Идентичность/gear/relations сохраняются.
4. Ровно2основателя с вьючными животными не оставляют animal-only неуправляемый caravan и не теряют животных/груз. Core добавил отдельный Animals holder без расхода cap работников. Сохранить Reference/WorldPawns регистрацию (как native caravan), IThingHolder tree и ShouldTickContents=false для абстрактно хранимых работников. Map-переключения/эвакуация учитывают AllPawns (работники+животные), но труд/лимит только людей. Перенесённый из carry груз действительно принадлежит доступному складу.
5. Фабрика: существующие RecipeDefs, Research, skill/bench; native IngredientCount.CountRequiredOfFor учитывает small-volume (Gold0.3 в XML означает3монеты золота в реальном рецепте). Реальные стэки/пределы, подтверждение TryAdd; не терять материалы при отказе продукта. Core содержит явные собственные рецепты/исследования синт-/гиперткани (StrategicTextiles.xml) — закончить локализацию и включить соответствующие ProductDefs. Это наши новые технологии, не выдуманный vanilla recipe. Исходные ориентиры: Synthread1 изCloth1+Chemfuel1 (Crafting8/Fabrication), Hyperweave1 изSynthread1+Chemfuel1 (Crafting12/AdvancedFabrication + наш текстильный research), нормы4/2на работникаSkill10всутки; цифры — provisionalbalance. Сверить реальный XML Core и корректно оформить research/recipeUsers.
6. Карты: первый визит настоящее nativeGenerate/CaravanEnter, те же люди/вещи. L1>=2коек, L10>=11; настоящие комнаты/двери/крыши/свет/станки и проходимость. Повторный визит/загрузка не стирает вручную построенный объект/повреждения. Апгрейд добавляет модуль, без места — отказ ДО серебра. Отсутствует ловушка людей/вещей в owner и физическая работа тех же пешек параллельно абстрактной. Переход к автономности запрещён в бою, ростер отделён от приезжего caravan. Сохранённый map может оставаться загруженным (TPS-границу назвать честно).
7. Реальное сырьё/получатель/суточные посылки: безопасный holder, при отсутствии/блоке получателя удержать груз. Выбор получателя не заменяется другой колонией молча; target полон дляPlanetTile layer, если поддерживаются только наземные колонии — явный фильтр. Ни деньги, ни вещи не начисляются повторно после reload.
8. UI: у неактивных вкладок нельзя передавать isActive как enabled в Widgets.ButtonText (это блокировало все вкладки). Должны реально работать депозит сырья/серебра и получение вещей с соблюдением веса, персонал/эвакуация/четыре типа/колония. Никаких Remove+GiveThing без подтверждения. Все численные и текстовые места/DefInjected RUEN/реальные иконки. Texture WorldObjectDef называется texture, не texturePath.
