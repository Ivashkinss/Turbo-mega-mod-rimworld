# Задание Gemini: текстура вспаханной почвы

Создай только новые оригинальные растровые ресурсы. Не меняй код, XML, настройки игры, Git или существующие ресурсы. Разрешена запись исключительно в `Tools/Build/GeminiSoilAssets/` внутри этого репозитория. Сеть и сторонние картинки не нужны.

Нужны:

1. `TilledSoil.png`: 256×256 RGBA, полностью непрозрачная бесшовная текстура тёмной коричневой земли с неглубокими параллельными бороздами. Вид сверху, мягкий стиль RimWorld, без растений, объектов, рамок и текста. Переход через каждый край должен быть непрерывным. Для тайлинга используй периодические функции/шум, не нарисованную рамку. Соседние крайние пиксели не обязаны быть идентичными, но не должно быть скачка яркости. Без чёрных провалов и чрезмерного контраста.
2. `TillSoil.png`: 128×128 RGBA, иконка вспашки (ручная мотыга над несколькими бороздами), прозрачный фон, отступ минимум 8 px, читается в 64×64, без букв.
3. `preview.png`: каждый ресурс на светлом и тёмном фоне, плюс текстура в сетке 3×3 для проверки швов.
4. `make_assets.py`: воспроизводимый генератор на уже установленном Python/Pillow. Папка вывода определяется через `Path(__file__).resolve().parent`. Не читать пользовательские файлы, не устанавливать зависимости, не запускать игру. Два запуска должны давать идентичные SHA256. Генератор пишет только в свою выходную папку.
5. `manifest.json`: размеры, режим, SHA256, прозрачные/непрозрачные пиксели, показатели скачков яркости на швах по сравнению с соседними строками/колонками.
6. `REPORT.md`: список результатов и команда воспроизведения.

Не добавляй новые моды, не копируй ресурсы в Textures, не запускай git. Codex самостоятельно проверит и подключит результат. Текущее рабочее дерево Codex может изменяться параллельно — его не трогать.
