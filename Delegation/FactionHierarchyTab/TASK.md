# FactionHierarchyTab — вкладка «Фракции» с иерархией героев

kind: implement + run · assignee: gemini (Antigravity) · afterTask: OutpostTabStageA

Пользователь хочет в нижнем меню кнопку просмотра всех фракций и их иерархии. Данные о героях уже есть: `Source/HeroRegistry.cs` (`HeroRegistry.Instance`, `HeroRecord`: `heroDefName`, `pawn`, `state`; `HeroState`: Unspawned, AtHome, Away, Captive, Dead, Joined, Missing) и `Source/HeroDef.cs` (`factionDef`, `rank` 3/4, `isLeader`, `councilMember`, `successor`, имена). Описание — `Documentation/HERO-REGISTRY-DESIGN.md`.

## Сделать
1. **Кнопка.** `Defs/MainButtonDefs/MainButton_Factions.xml`, подпись «Фракции» / "Factions", класс `TurboMegaMod.MainTabWindow_FactionHierarchy`. Ставь её рядом с «Аванпосты». EN-подпись в Def, RU — в DefInjected.
2. **Окно, слева.** Список всех видимых фракций мира: сначала наши, у которых есть HeroDef, потом остальные. У каждой показаны иконка и цвет, название, отношение к игроку (число и «союзник / нейтрал / враг»), лидер и число поселений.
3. **Окно, справа.** Иерархия выбранной фракции деревом:
   - лидер, а у фракции с `councilMember` — совет;
   - ниже герои ранга 4, ещё ниже — ранга 3;
   - у каждого героя: портрет (`PortraitsCache`), имя с прозвищем, ранг, состояние и место (дома, в пути, в плену у такой-то фракции, погиб, присоединился к колонии);
   - наследник лидера отмечен стрелкой или значком «наследник»;
   - если лидер погиб, видно, кто его сменил.
   Клик по живому герою на карте или в караване — «Показать» через `CameraJumper`. Подсказка с биографией из backstory.
4. **Незнакомые герои.** Пока игрок не встречал героя, показывай силуэт «Неизвестный герой (ранг N)», без имени и состояния. Встреча — это любое из трёх:
   - пешка героя появилась на карте игрока;
   - пришло письмо с ней;
   - она в плену или присоединилась.
   Добавь поле `known` в `HeroRecord` с сохранением (Scribe, по умолчанию false) и ставь его в существующих местах, где обновляется состояние. Лидеры фракций, с которыми есть контакт, известны сразу.
5. **Фракции без героев** показывают только лидера (vanilla `faction.leader`) и строку «Иерархия неизвестна».
6. Все строки — в EN и RU Keyed. Только C# 5: без `?.`, `=>`-членов, `nameof` и `is X x`.
