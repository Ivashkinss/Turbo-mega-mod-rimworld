# Gemini: сценарии упрощения теплиц и гостиницы

Читать только замороженный `Tools/Build/ComplexSimplificationSnapshot/` и этот TASK. Снимок показывает СТАРОЕ поведение: Codex сейчас меняет реализацию. Запись строго в `Tools/Build/GeminiComplexSimplificationAudit/`. Не менять исходники, XML, DLL, игру, настройки, сохранения, Git и прежние отчёты. Без сети и запуска игры/DLL.

Новые требования пользователя:
1. Отдельно строить стеклянные стены/двери/климатические панели нельзя: только план теплицы разметкой. Расширение существующей теплицы меняет периметр и площадь с обычной стоимостью строительства, без бесплатных построек и обрушения крыши. План расширения сохраняется.
2. Одна территория комплекса для гостей и персонала. Обычные кровати автоматически гостевые, медицинская отметка на кровати обозначает весь закрытый медблок. Колониальный лазарет вне территории не входит в клинику. Кровати персонала с явно назначенным проживанием нужно сохранить обычными. Стол в комнате с гостевой кроватью только для постояльцев этого номера; столы в медблоке не считаются приватным рестораном. Припасы берутся из холодильников комплекса, при отсутствии подходящего блюда — из доступных холодильников колонии. Не брать испорченное/недоступное/диетически запрещённое. Все настройки на ресепшене или нижней панели; на кровати оставить обычную медицинскую отметку.
3. Встроенная лампа гидропоники не даёт свет для роста соседней обычной ванне. Проверить собственные 4 клетки и соседей при всех поворотах, питании, солнце/затмении/ночи. Не отнимать настоящий солнечный свет или свет от обычной солнечной лампы.

Подготовить:
- `CASES.json`: 25–35 независимых сценариев с id, подготовкой, действиями, ожидаемым результатом и сохранностью ресурсов. Разделить fresh/save-load и изменения старого сохранения. Не выдавать сценарии за выполненные тесты.
- `BED-GIZMOS.md`: по исходникам снимка точные классы/методы всех добавленных Hospitality/Hospital кнопок на кроватях; отдельно какие обычные кнопки движка GuestBed блокирует и какие данные Swap сохраняет/теряет. Не делать выводов о неизвестной реализации движка.
- `REPORT.md`: до 12 существенных рисков для Codex с точными путями. Особенно учитывать смену Thing-ссылки при Swap, сутки HotelStay, владельцев/проживание, паузу между новым периметром и демонтажем старого, наличие семи холодильников/разных размеров. Никаких правок кода.
