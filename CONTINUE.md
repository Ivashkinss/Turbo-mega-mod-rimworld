Нужен Python 3 с lxml. На этом компьютере доступен bundled Python Codex, но не переносить его абсолютный путь в общие скрипты. При наличии только RimWorld 1.7 загрузить compile-only reference assemblies через Tools/fetch_build_references.py. Версия 1.6.4871 и SHA-256 закреплены в скрипте; пакет не коммитится.

Tools/build_assembly.ps1 использует справочные библиотеки 1.6, установленные Adaptive Storage и Harmony 1.6; результат загружается в 1.7 через перенаправления самого движка. Нельзя смешивать старые Unity-ссылки Adaptive Storage с UnityStubs при компиляции. Пересборка сначала идёт в Tools/Build, готовая DLL заменяется только при успехе и закрытой игре.

Далее: визуально проверить настройки анимаций, варианты смещения тел, команды лассо/добивания, боевой журнал, торговлю и её подсказки. Потом продолжать интеграцию остальных согласованных компонентов из Documentation/MODS.md. Сохранить Melee Animation и Show Me Your Hands; не включать три согласованных исключения из README. Исторические аудиты оригиналов не считать текущим покрытием перевода.
