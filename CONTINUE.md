## Инструменты

Python 3 с lxml. На первом компьютере использовался встроенный Python из среды Codex; на другом компьютере найти доступный Python, не копировать абсолютный путь первого ПК в команды.

- Tools/build_combat_localization.py — строит переводы определений и боевой грамматики из словарей.
- Tools/build_runtime_localization.py — строит ключи и C#-таблицу встроенных текстов.
- Tools/build_assembly.ps1 — собирает DLL. Нужны установленная игра, Adaptive Storage и Harmony по путям, указанным в скрипте.
- Tools/test_runtime_localization.ps1 — 8 проверок с настоящей Harmony, временные файлы в игнорируемой Tools/Build.
- Tools/inspect_ui_literals.ps1 — читает метаданные DLL без исполнения и помогает проверить реальные UI-цели.

Репозиторий содержит наш мод, а не игру и не все исходные моды. Для игрового испытания на втором компьютере потребуются соответствующие исходные зависимости. Не включать исходные Neat Storage и Fridge вместе с нашим модом.
