# Изменения 11 ноября 2026

Завершена техническая проверка русификации Melee Animation и Dynamic Trade Interface, сохранённой предыдущим checkpoint. Строки XML сохранены; исправлены реальные цели перехвата названия настроек торговли и форматирования CorpseOffsetMode, а также сохранение тегов при получении перевода.

Добавлена узкая поправка Melee Animation для 1.7: ленивый список возможных участников дружеского поединка материализуется на потоке тика перед Parallel.ForEach. Прежний код воспроизводимо обращался к MapPawns из фонового потока. В исходный мод изменения не вносились.

About объявляет Harmony обязательной зависимостью, порядок после двух переводимых компонентов и поддержку 1.7. LoadFolders явно использует те же ресурсы для 1.6 и 1.7.

Сборка работает на компьютере без Unity/Managed: закреплённые compile-only ссылки RimRef 1.6.4871 сохраняют общий ABI с внешними библиотеками 1.6. Загрузка пакета проверяется по SHA-256. Проверка хранилищ теперь работает без удалённых по просьбе пользователя оригиналов, используя сохранённые данные вместимости, 10 baseline XML и 240 хешей графики. Хеш рабочего кода раскладки нормализуется по LF.

Проверки: 17 runtime регрессий, 720 случаев неизменённой раскладки, XML/параметры/разметка/грамматика, игровой probe на RimWorld 1.7.5000. В реальной игре совпали 968 ключей, 225 полей, 45 строк грамматики и шесть перехватов. После probe наблюдалась минута работы новой колонии; потоковый сбой не повторился. Визуальный просмотр не выполнен из-за тайм-аута захвата окна.

Внешняя среда: по отдельному согласию пользователя обновлена Harmony до версии мода 3.0.2.0 (Harmony 3.0.0-rc.5 для 1.7); резервная копия старой версии в Tools/Build/Harmony-before-3.0.2.0. Официальный архив: https://github.com/pardeike/HarmonyRimWorld/releases/download/v3.0.2.0/HarmonyMod.zip, проверенный SHA-256 7a8f59136690191a03172be290cecf50e8f9611a916e40df0ec02f126d484923. Архив и резервная копия в Git не включены.

В игровом отчёте отдельно отмечены две ошибки дефектного русского правила Odyssey. Прямая проверка архива установленной игры подтвердила отсутствующий keyword-> в DefInjected/RulePackDef/RulePacks_Namers_Factions.xml:138. Также остались исходный повреждённый Actions.xml Dev In Your Language и девять устаревших путей перевода Core/DLC. Эти чужие файлы не редактировались. Проверка не означает совместимость всего установленного списка модов или всех игровых сценариев.


## Диагностика вылетов и продолжение объединения

Вылет VK_ERROR_DEVICE_LOST воспроизведён добавлением одной Camera+ к рабочей основе. По просьбе пользователя Camera+ удалена из папки модов и активного списка с резервной копией списка; исключена из плана. Новая карта полного оставшегося набора и копия пользовательского сохранения отрисовываются без GPU-вылета в проведённых тестах. Ограничения и все результаты, включая неудачные проверки, записаны в CrashInvestigation.json.

Замер MapPreview.TrueTerrainColors: 42656 мс на холодном тестовом профиле. Поздние тесты копируют существующий пользовательский кеш цветов, поэтому не повторяют эту подготовку. Код Map Preview не менялся.

Встроены Smart Speed и Smarter Construction, добавлены условные LoadFolders для предотвращения двойной загрузки, сохранены исходные About и хеши файлов. Проверена загрузка обеих DLL именно из Components, а также наличие их игровых патчей. Старый 0Harmony.dll из Smart Speed не копируется. Добавлен русский перевод Smart Speed и его категории настроек.

По скриншоту пользователя переведены 21 ключ окна VEF, предлагающего добавить отсутствующую фракцию: заголовок, пояснения, кнопки и результаты. Все подстановки сохранены. Всего 1239 русских записей. Финальная сверка внутри игры: 1006 ключей, 225 полей, 45 строк правил и 7 перехватов; 18 runtime проверок проходят.

На новой карте зафиксированы 4256 кадров и 1784 тика за 30 секунд. Копия сохранения оставалась на паузе из-за модального окна VEF; 4233 кадра при нулевых тиках подтверждают отображение, а не активную симуляцию. Оригинальный .rws не менялся. Старые Camera+ компоненты дают предупреждения при загрузке; игровой probe и карта всё же загрузились. Оставшееся предупреждение VEF и исходные проблемы переводов не объявляются исправленными.
