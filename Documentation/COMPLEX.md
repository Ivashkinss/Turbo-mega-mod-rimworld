# Руководство игрока: Управление гостиничным комплексом

## 1. Стойка управления (Ресепшен)
* **Размещение**: Вкладка «Производство» -> «Стойка управления комплексом» (1×1 клетка, 60 дерева, 25 стали). На карте допускается **строго одна стойка**.
* **Территория комплекса**: Задаёт общую границу комплекса (номера, ресторан, служебные комнаты). Без назначенной области стойка неактивна. Для режима «Только комплекс» включите в территорию рабочие места и нужные им запасы.
* **Гостевая область и запасы**: Назначаются отдельными разрешёнными зонами: гостевая зона ограничивает перемещение постояльцев, а зона запасов выделяет готовые порции для официантов.
* **Применить настройки служб**: Назначает зоны ненастроенным стойкам-кассам ресторанов и задаёт область по умолчанию новым группам гостей Hospitality. Индивидуальные настройки уже настроенных ресторанов и гостей сохраняются.
* **Сводка доходов**: В строке осмотра отображается фактически полученное серебро (номера, блюда, клиника) с момента установки стойки; это статистика, а не новые деньги.

## 2. Персонал и режимы работы
В окне «Персонал и проживание» (кнопка на стойке) для каждого поселенца настраиваются:
* **Три режима работы**:
  * **«Только колония»**: Поселенец выполняет автоматическую работу только за пределами территории комплекса.
  * **«Только комплекс»**: Поселенец берёт задачи исключительно внутри территории комплекса.
  * **«Оба места» (по умолчанию)**: Поселенец работает везде. При отсутствии задач в комплексе (нет голодных гостей, нет пациентов) он свободно переходит к обычным задачам колонии (грядки, ремесло, уход за животными).
* **Свобода перемещения**: Режим работы фильтрует только автоматический выбор задач (`JobGiver_Work`). Он **не запрещает** поселенцу выходить из здания ради отдыха, приёма пищи, сна, визита к врачу, тушения пожара или по прямому боевому приказу игрока.
* **Смена режима**: Новый режим вступает в силу при следующем поиске работы, когда колонист завершит текущее действие.

## 3. Назначение ролей и приоритеты
* **Роли**: Доступны роли «Официант», «Повар», «Врач», «Администратор», «Уборщик». Администратор повышает работу «Дипломатия» Hospitality для общения с гостями.
* **Сохранение приоритетов**: Назначение роли выставляет профильной работе приоритет 1, запоминая исходный приоритет поселенца. Все остальные работы не обнуляются.
* **Отображение в интерфейсе**: При стандартных приоритетах-галочках приоритет 1 отображается обычной зелёной галочкой (штатный интерфейс RimWorld).
* **Снятие роли**: При выборе «Без назначения» исходный приоритет восстанавливается, если игрок не изменил его вручную.

## 4. Проживание в комплексе
* **Независимость от работы**: Проживание настраивается отдельно от режима работы.
* **Требование к кровати**: Для заселения («Поселить в комплексе») внутри территории комплекса должна быть **свободная обычная кровать поселенца** (не медицинская и не гостевая).
* **Выселение**: При снятии проживания бронь снимается. Если исходная домашняя кровать поселенца в колонии свободна — он возвращается в неё; если занята — остаётся без кровати до ручного назначения.

Клиника ещё проходит интеграцию: роль «Врач» сейчас задаёт штатную работу врача, а строка дохода клиники зарезервирована для следующего этапа. Развлечения обеспечиваются обычными доступными гостям объектами отдыха; отдельной платы за них пока нет.
