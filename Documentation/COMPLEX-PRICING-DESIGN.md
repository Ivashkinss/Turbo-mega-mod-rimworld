# Цены магазина и тариф всей кровати

Пользователь подтвердил цену за всю кровать в сутки, независимо от двух занятых мест. Управление на ресепшене; лишние кнопки на кроватях не возвращаем.

- Магазин: регулируемый процент рыночной стоимости, исходные55% сохраняются. При создании заказа фиксируются unitPrice/price; последующая смена процента действует на новые заказы. Для оптовиков сохраняется реальный бюджет/вес; ассортимент для частоты визитов оценивается по market value.
- Кровати: общий roomRate и индивидуальное исключение на конкретную кровать. Применение к комнате — настройка всех её текущих гостевых кроватей, а не цена всего помещения. Новый объект после обычного разрушения получает общий тариф; при штатном Swap guest/medical тариф переносится явно между объектами.
- Первый гость оплачивает всю кровать на60000тиков. Второй допустимый штатными правилами постоялец присоединяется к уже оплаченному периоду без второй полной платы и без сдвига общего срока. Новый срок не отсчитывается от позднего подселения.
- Продление: за кровать собирается ровно один полный тариф. Средства берутся последовательно у текущих постояльцев; общая сумма не превышает стоимость кровати. При недостаточном общем бюджете номер освобождается для обоих с безопасным Wake смертосна; не создаются ни серебро, ни возвраты из воздуха.
- Оплаченный период сохраняется после ухода одного гостя, если второй остался. При полном освобождении кровати бронирование заканчивается; следующий посетитель оплачивает новый период. Старые уже выплаченные суммы по прежней по-гостевой модели автоматически не возвращаются.
- HotelStay остаётся на каждого гостя, но nextChargeTick/remaining/periodFee синхронизируются по одной кровати. Для старых несогласованных сроков сохраняем наиболее поздний оплаченный срок; не объявляем историческую сумму новой общей выручкой. Pending-платёж сохраняет зафиксированныйperiodFee при редактировании тарифа.
- Временная переноска/контейнер не стирает HotelStay. Физическая оплата общей кровати откладывается, пока любой постоялец временно не заспавнен; сроки/остаток сохраняются. Это продолжение существующего правила, не новая генерация денег.
- Смена тарифов действует при следующих сутках. Отдельные платёжные квитанции учитывают реальные монеты конкретного плательщика в досье и доходах. Общая оплата не записывается дважды обоим гостям.

Подсказки должны явно говорить «за всю кровать в сутки». Сохраняем штатные ограничения совместного сна/идеологии/мнения; не гарантируем что любые двое случайных гостей захотят делить кровать.

Пользователь отдельно подтвердил: один гость может арендовать двуспальную кровать целиком, два постояльца могут делить её только при текущих романтических отношениях (супруги/помолвлены/любовники). Для чужого постояльца действует явный запрет подселения, в дополнение к нативным ограничениям.
